# EduNova — Agente de IA Corporativo (RAG)

Agente de IA que responde perguntas de colaboradores/alunos com base em documentos internos
da EduNova (plataforma educacional fictícia), usando LangChain + LangGraph, Oracle Database 23ai
(AI Vector Search) e deploy na Oracle Cloud Infrastructure (Always Free).
